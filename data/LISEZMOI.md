# Fichiers du club

Les fichiers placés ici sont chargés automatiquement par le jeu sur tous les appareils
(appli web, appli installée, Quintet.exe), puis rechargés dès qu'ils changent.

| Fichier | Contenu |
|---|---|
| `joueurs.txt` | Le fichier de joueurs (LIGUE\|EQUIPE\|SIGLE\|POSTE\|PSEUDO\|…). |
| `logos.zip` | Les logos d'équipe, nommés par sigle ou nom d'équipe (`G2.png`, `T1 Esports Academy.png`). Logo de ligue : `_LOGO_LIGUE_LEC.png`. |
| `champions.zip` | Les images de champions, nommées par champion (`Ahri.jpg`, `lee_sin.png`). |

Pour mettre à jour : sur GitHub, ouvrez ce dossier, « Add file » → « Upload files »,
glissez le fichier avec le même nom, puis « Commit changes ».
