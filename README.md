# Quintet — Esport Manager

Jeu de gestion d'équipe esport League of Legends, jouable dans le navigateur, installable comme application (Android, iPhone, PC) et jouable hors ligne.

**Jouer :** https://yatoohpro.github.io/Qintet/

**Windows :** [télécharger Quintet.exe](https://github.com/yatoohpro/Qintet/releases/latest/download/Quintet.exe) (se met à jour tout seul à chaque lancement).

## Installer
- **Android (Chrome)** : bouton « Installer l'application » sur l'écran d'accueil du jeu, ou menu ⋮ → « Installer l'application ».
- **iPhone (Safari)** : bouton Partager → « Sur l'écran d'accueil ».
- **PC (Chrome ou Edge)** : bouton « Installer l'application » du jeu, ou l'icône d'installation dans la barre d'adresse.

L'application se met à jour toute seule dès qu'elle est connectée.

## Contenu
- `index.html` : le jeu complet (moteur, interface, mercato, match en direct).
- `manifest.webmanifest`, `sw.js`, `icons/` : application installable et mode hors ligne.
- Sauvegardes dans le navigateur de chaque appareil (export et import de fichier dans Parties).
